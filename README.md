# Claude 订阅防封保姆级教程

作者：王勇。教程正文、截图和 APK 下载入口的独立网页版本。

- 阅读地址：https://wangyong5609.github.io/claude-subscription-guide/
- 安装包附件：https://github.com/wangyong5609/claude-subscription-guide/releases/tag/attachments-v1
- 问题反馈：https://github.com/wangyong5609/claude-subscription-guide/issues

## 文件

`index.html` 是完整正文；`assets/` 是教程截图；`style.css` 与 `script.js` 提供手机排版、目录、图片预览和提示词复制。网页不依赖飞书登录或图片外链。原文中两张含邮箱的截图已用不含账号的邮箱选择、关联地区示意替代。

APK 保持飞书附件原始字节，存储于 Releases，未提交到 Git 源码。`downloads.json` 记录原文件名、字节数和 SHA-256，用于核对下载完整性。

## 更新

修改网页文件后提交并推送 `main` 分支，GitHub Pages 自动更新。APK 更新时另建 Release，并同步网页中的下载地址、版本和校验值。
